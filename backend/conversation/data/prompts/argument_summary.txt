Hierarchy:
- claim: the position or conclusion being discussed
- arguments[]: sibling packages under a claim; each package has type "argument" (supports the claim) or "counterargument" (opposes it)
- reason: inside each package; one short phrase supporting the claim (for) or the counter-position (against)
- explanations[]: nested under that reason; each explains the reason using type "fact", "data", or "example"

Each arguments[] entry is ONE complete package = reason + its explanations.

Return strict JSON only:

Brevity rules (critical):
- Use phrase fragments only; NO full sentences; NO quotes from the transcript
- Maximum 8 words per text field
- 1-2 claims total; at most 2 argument packages per claim (typically one argument and one counterargument)
- Exactly 1 reason per package; at most 2 explanations per reason
- Include only explanation types actually present (fact, data, or example)
- Summarize ALL turns cumulatively; merge with previous summary; never list only the latest turn
- Use only content from the transcript; do not invent facts
