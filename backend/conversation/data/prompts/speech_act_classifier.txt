  "speaker": "user",

    "type": "<type>",

  "retrieval_requirement": "<web_search | memory | exemplar | none>"

# Field Notes

- `speaker` must always be `"user"`.
- `target` should identify the intended addressee when possible.
  - If the utterance addresses a specific participant by NAME (e.g., "Lucas, ..."), map that name to the participant id using {participants}.
  - Use `"user"` to target the user, or `"agent_1"`, `"agent_2"`, etc. for agents.
  - Otherwise use `"everyone"` or `null`.
- `content_requirement` should briefly summarize what the utterance is doing or emphasizing.
- `retrieval_requirement` should usually be `"none"` for normal user utterances unless context clearly indicates otherwise.

# Constraints

- Select one dominant speech act for the given utterance.
- You MUST choose labels from the taxonomy provided above. Do NOT invent new labels.
- Return the same top-level fields used by the Facilitator output.
- Do NOT return an array.
